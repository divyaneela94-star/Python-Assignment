# Title: 1.Data Structures – Strings & Tuples

This assignment demonstrates how Python handles strings (which are immutable sequences) and tuples (immutable ordered collections).

## 📌 Part 1: Strings
Features Covered

✔ Concatenation
✔ Indexing
✔ Slicing
✔ String methods (upper, lower, capitalize, count, replace)
✔ Reversing a string
✔ Extracting specific words using slicing

## 📌 Part 2: Tuples
### Features Covered

✔ Tuple creation
✔ Tuple concatenation
✔ Tuple repetition
✔ Element access by index
✔ Slice operations

## 📌 Learning Outcomes

### By completing this project, students will:

Understand how to manipulate strings efficiently

Learn core slicing techniques

Use important string functions to transform data

Understand tuple operations and immutability

Practice combining, repeating, and indexing tuple elements.

# ✅ Tittle 2: List, Dictionary, Set & Conditional Statements

This assignment demonstrates practical use of Python’s core data structures and decision-making statements. 
It reinforces concepts crucial for early programming mastery.

## 📌 Lists

-Create lists of numbers and names

-Add, insert, remove, pop, and extend elements

-Sort lists, find max/min/sum

-Access elements using indexing and slicing

-Reverse lists

-Lists are ideal for storing ordered and changeable collections.

## 📌 Dictionaries

-Map student names to marks

-Update and add entries

-Access values

-Use .keys(), .values(), and .items()

-Dictionaries store data in key–value pairs, making lookups fast and intuitive.

## 📌 Sets

-Unique element storage

-Behavior of sets with duplicates

-Why sets cannot be indexed

-Union and intersection operations

-Sets are useful for mathematical operations and eliminating duplicates.

## 📌 Conditional Statements

-Accepts a score

-Categorizes performance using if–elif–else

-Prints helpful feedback

-This teaches decision-making based on user input—an essential programming concept.
